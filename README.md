# PRSNTSTUATN Shopify theme download

Download [PRSNTSTUATN-theme.zip](./PRSNTSTUATN-theme.zip).

On the ZIP file page, click **Download raw file** (the downward arrow near the top right). If GitHub asks you to sign in, use the account that has access to this repository.

In Shopify, go to **Online Store → Themes → Add theme → Upload zip file** and choose the downloaded ZIP. This adds an unpublished theme for review.

The theme includes the PRSNTSTUATN brand, a blonde/khaki/russet palette, editable homepage sections and native product, collection, search and cart templates. Select your real featured collection in the theme editor and replace illustrative images as needed. Live checkout and newsletter delivery must be tested on Shopify before publication.

Shopify Theme Check passed with no offenses. All 47 local browser checks passed against illustrative sample data.

This delivery branch contains the upload-ready archive only. It does not publish or change a live Shopify store.
